# Install Backlot for Movieguide

Backlot 0.1.0, build 373. For Macs running macOS 14 or later, including Apple
Silicon and Intel.

Download: https://github.com/ChrisWach/backlot-releases/releases/download/v0.1.0-376/Backlot-0.1.0-376-prod.dmg

1. Download and open the DMG. Drag Backlot into Applications.
2. Eject the Backlot disk and open Backlot from Applications.
3. If macOS blocks the app, first try opening it, then go to System Settings
   > Privacy & Security > Open Anyway and confirm. This internal release is
   signed with Backlot's own certificate and is not Apple-notarized.
4. On the welcome screen, choose Continue with Google. Returning users can choose Sign In from the account menu, then Continue with Google. Pick your @movieguide.org
   Google account. Personal Gmail and movieguide.com do not qualify.
5. If macOS asks to let Backlot use its saved key, enter your Mac login
   password in that macOS dialog and choose Always Allow for this trusted
   Backlot copy. Never put a password in a chat, email or problem report.

Already using Backlot? Quit it before replacing it in Applications, or use
Backlot > Check for Updates once build 373 is offered. Keep the same app
location. Do not remove Backlot's saved data or Keychain items.

Guest pages stay on the Mac and are separate from the team workspace.
To report a problem, use Help > Report a Problem and describe the steps that
led to it. Include the build number from About Backlot.

Page comments and reporting-line screens remain unavailable in this release.
For the first team session, have two coworkers edit a shared test page and
confirm each can see the other's changes after closing and reopening it.

Team invitation link: https://chriswach.github.io/backlot-releases/join/
Choose your superior and direct reports during setup. Home lets you return to team requests and Learn Backlot. Email delivery is pending; use Copy invitation link for now.
